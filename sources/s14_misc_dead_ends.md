# Sources tried and not usable (so the next pass doesn't repeat them)

| Source | Why tried | Outcome |
|---|---|---|
| Neal, *Course of the Exchange, London 1698–1823 and Amsterdamsche Beurs 1723–1794*, ICPSR 1008 | Daily EIC and VOC prices — the ideal dataset | Login-walled; GitHub mirror search blocked (no linked account). |
| Van Dillen, "Effectenkoersen aan de Amsterdamsche beurs 1723–1794", *Economisch-Historisch Jaarboek* 17 (1931) | Dutch-language VOC & EIC price series | Not digitised on any reachable host (DBNL/Delpher searches fruitless). |
| Thorold Rogers, *History of Agriculture and Prices* vol. VII pt 2 (1902), Doc. XV "Prices of stock — East India Company" | Annual EIC prices 1703–1793 | archive.org PDF reachable but the table OCR is unreadable ("1724 1725 July 21 8^4"). |
| Gentleman's Magazine vols 15–20 (1745–50), archive.org s2492id1330001 etc. | Monthly "Price of Stocks" incl. India | Item page reachable; djvu full text blocked by fetch allowlist. Only Jan 1731 (Gutenberg) usable. |
| Macpherson, *Annals of Commerce* vol. 3 (1805) | Year-by-year EIC notes | archive.org fetch failed (client error). |
| Odlyzko, 18th-c. Course of the Exchange collections (umn.edu) | Daily closes | robots.txt disallows fetch. |
| Petram, *The World's First Stock Exchange* (2011) | VOC prices | Covers 1602–1700 only. |
| Phung (2013) Tilburg MSc thesis | Van Dillen prices 1723–36 | No price table reproduced. |
| Nierstrasz (2008) Leiden diss. | VOC decline 1740–96 | Only the abstract page was readable. |
| De Korte (1984) *De jaarlijkse financiële verantwoording in de VOC* | Year-by-year VOC dividends | Not online; only the decade revenue table via Vink (s08). |
| Generale Missiven XI (1743–50), Huygens | Dutch primary on Batavia/opium | Front page reachable; text viewer needs JS. Used the Amfioen inventory instead (p04). |

Consequence: there is no reachable source giving exact EIC and VOC prices for each month of
1745–50. The paper therefore uses documented anchor points plus explicit scenario ranges
(notes/02) and shows that the recommendation does not depend on where in those ranges the
true prices lay.
